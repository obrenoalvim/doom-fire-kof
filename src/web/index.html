Doom Fire, ported to Kof

Same algorithm as filipedeschamps/doom-fire-algorithm. Fire spawns at max intensity along the bottom row; each pixel copies the one below it with random decay and a slight horizontal drift, mapped through a 36-step palette. The terminal build runs on Kof itself, JVM target, in src/cli/Main.kf. This page runs the same algorithm in JS, served straight off disk by Kof's own web server in src/server/Server.kf.

FIRE INTENSITY Ember Inferno
Algorithm
Column-by-column fire propagation. O(width × height) per frame, 36-step palette lookup, zero allocation in the hot loop.
Kof source
initFire · spreadFire · doFire · render. Four top-level functions, flat Int[] buffer, no classes needed.
Palette (index 0 → 35)
Black-body ramp: ember, orange, amber, pale flame, white.
Terminal target
24-bit ANSI background per cell, time.sleep(40) between frames, while (true) looping in a background shell right now.
